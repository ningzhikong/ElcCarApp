# 实车控制阶段总结（2026-10-26）

本阶段已从架空等速核对推进到带航向纠偏的落地直行验证。最关键的结果是：两轮平均RPM相同仍会持续左偏；实物确认陀螺仪偏航为X轴、左转为正后，加入有界航向外环，90 RPM落地直行明显改善，130 RPM在末段外部干预前基本保持方向。

## 已完成

- 复核独立编码器比例：左1080、右1320计数/圈，保留各自RPM换算，不以统一PWM或错误修改CPR强行等速。
- 完整保存每10ms编码器/PWM数据，停车后导出并重放测速反馈；15秒长测每30ms汇总全部计数，不丢弃中间控制周期。
- 手动双向检查实物偏航轴，修正原Y轴假设为X轴/+1，并统一正常路线的轴选择和零偏索引。
- 独立直行固件加入航向PD：Kp0.6、Kd0.12、修正最大6 RPM、变化20 RPM/s；倒计时末锁定出发航向。误差超过25度、IMU过期或失败时停车，保留原堵转、方向、采样周期和本地停车保护。
- 停车显示和SWD读回全控制周期的两轮计数积分、平均PWM、限幅占比，以及航向误差；新增IMU初始化/校准摘要，保留失败原因而不放宽静止门限。
- 增加电机锁定的IMU诊断、被动航向观察、回归测试及完整硬件工具启动入口。硬件依赖固定在tools/requirements-hardware.txt。

## 实测结果及边界

| 档位 | 结果 |
|---|---|
| 90 RPM落地 | 用户反馈“走得很直”；完整10秒后正常停车，最终航向误差+2.62度，稳态积分左87.43/右87.84 RPM；左PWM300限幅占比约34.7%。作为本地已观察成功基线保存。 |
| 100 RPM架空 | 左99.94/右100.03 RPM，原匹配判据通过；PWM350上限下稳态未限幅。 |
| 100 RPM落地 | 用户反馈仍可保持方向；接回时只剩启动故障状态，无完整运行日志，不能定量认定通过。 |
| 130 RPM架空 | 左129.64/右130.06 RPM，原匹配判据通过；稳态无PWM450限幅，用户未观察到异常。 |
| 130 RPM落地 | 用户反馈基本直行；干预前稳态航向误差约-1.05～+0.51度。约8.4秒发生用户确认的碰撞或手动干预，8.93秒因偏航超过25度触发111保护停车。未完成无干预的完整10秒验证。 |
| 150 RPM | 未实现或测试，不列为已验证能力。 |

当前高档参数仅作用于专用直行诊断：130 RPM/PWM450、总10秒、前2秒20→130。普通路线和循迹仍20 RPM/PWM150。原计数RUN、JOG和15秒长测分别保留各自较低边界。
