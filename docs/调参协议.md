# USART1 独立速度实验协议 v1

2026-10-16。状态：已实现并完成主机模拟检查，尚未烧录或实车验证。

## 模式与算法

Start/PB14 在启动选择窗口保持低电平，锁定调参模式；否则进入正常视觉模式。两种模式共用唯一的 UART HAL 回调，再由串口路由器分发。调参模块不会处理视觉结果，正常模式不会接收实验命令。

串口 115200、8N1、无流控；ASCII 命令，每条 LF 结束，接受 CRLF。只允许一个主机占用串口。接收环形队列 256 字节，命令最多 127 字节，溢出或非法字节取消实验并等待换行重新同步。

算法为左右独立增量式 PI，Kd=0，周期 10ms：

```text
du = Kp*(e[k]-e[k-1]) + Ki*e[k]
du 限幅 [-30,30]
u = clamp(u + du, 0, pwm_limit)
零目标显式取消驱动输出，使用当前 TB6612 接法的 PWM 低电平制动
```

速度单位 counts/10ms，反馈保留小数，滤波 alpha=1/8。输出单位 PWM 计数，周期寄存器 ARR=999。此版本不做 RPM 换算，不使用内部一阶电机模型。

## 命令

| 命令 | 响应及说明 |
| --- | --- |
| `HELLO` | `HELLO ELC_AUTOTUNE_V1 INC_PI_COUNTS_10MS 10 50 5500`，分别说明协议、算法/单位、控制周期、记录周期、实验时长 |
| `INFO` | `INFO ELC_INC_PI_V1 build_id`，自动搜索要求独立构建生成的固件指纹 |
| `VIEW` | `VIEW tick_ms raw_l raw_r speed_l speed_r period_us control_fault`，用于不通电驱动时检查方向和周期 |
| `ARM sign_l sign_r` | 符号各为 1 或 -1；要求非运行状态、无待应用 RUN、连续 30 个周期原始计数为零。成功返回 `ARMED sign_l sign_r`，不会驱动电机；授权 5 秒有效 |
| `RUN id kp_l ki_l kp_r ki_r peak pwm_limit` | 在下一控制周期整组应用，之后才返回 `ACK id kp_l ki_l kp_r ki_r peak pwm_limit` |
| `PING` | 刷新调参运行心跳，无响应 |
| `STATUS` | `STATUS id state fault count elapsed_ms armed encoder_quiet` |
| `STOP` | 取消待启动/正在运行的实验及 PWM，解除 ARM，返回 `STOPPED`；不表示已独立测得物理静止 |
| `DUMP` | 仅停止、完成或故障状态允许，返回 BEGIN、CSV、END；导出期间不要发送其他命令 |

RUN 的初始软件边界：id=1..1000000000，Kp=0..10、Ki=0..2，peak=1..25 counts/10ms，PWM 上限为整数 20..200。它们用于限制首版试验范围，**没有经过实车安全或性能标定**。不合法、NaN/Infinity、额外字段、未 ARM 或运行中重复 RUN 均拒绝，不启动第二次实验。

启动、结束、STOP 和故障都不会写 Flash。每次实验都需要 ARM；主机需先核对 HELLO，再运行，不能把模拟固件与实车固件混用。

## 固定目标与采样

| 时间 | 左右轮目标 |
| --- | --- |
| 0..500ms | 0 |
| 500..1500ms | 0.4 × peak |
| 1500..3000ms | peak |
| 3000..4500ms | 0.5 × peak |
| 4500..5500ms | 0，输出取消 |

每 50ms 记录一条，从 t=0 至最终停止共 111 条。样本在控制计算后记录，速度是本周期测速反馈，PWM 为实际写入的整数比较值。时间戳使用真实毫秒时钟；不能用行号推断实际时序。

```text
BEGIN id count
time_ms,raw_l,raw_r,target_l,target_r,speed_l,speed_r,pwm_l,pwm_r,period_us,flags
...
END
```

实际串口不发送上述列名行，列名由主机保存 CSV 时添加。flags bit0/bit1 分别表示左右实际 PWM 达到上限。故障试验可能不足 111 条，不能用完整试验评分规则接受。导出只能在取消驱动后执行，因此 UART 文本发送不进入实时控制任务。

## 保护与故障

state：0 空闲、1 运行、2 完成、3 已停止、4 故障。

| fault | 意义 |
| --- | --- |
| 0 | 无故障 |
| 1 | 驱动使能时控制间隔小于 5ms 或大于 15ms |
| 2 | 驱动目标超过 100ms 未刷新 |
| 3 | 控制层 UART 故障 |
| 4 | 控制目标非有限或超出公共 ±100 counts/10ms 边界 |
| 10 | 调参心跳 1000ms 到期 |
| 11 | UART 错误或 RX 队列溢出 |
| 12 | 任一轮输出至少 80，原始计数在 ±1 内持续 500ms |
| 13 | 正目标时任一轮原始计数小于 -2，连续三个周期 |
| 14 | 任一轮单周期原始计数绝对值大于 100 |
| 15 | 采样缓冲溢出 |
| 16 | 命令过长、非 ASCII 或 NUL 字节 |
| 17 | RUN 等待应用时 ARM 已过期，返回 ERR ARM_EXPIRED |

PB15 本地按键在控制任务中触发 STOP，不依赖前台串口解析。完成、按键停车、STOP、故障后取消 ARM。故障清除必须在停止条件满足后由新的 ARM 显式执行，禁止普通目标更新自行解除故障。

控制中断只做计数、浮点滤波、PI、实验目标/保护和采样，不调用 I2C、串口发送、延时或格式化函数。HardFault 等异常关闭 PWM 通道。尚未加入硬件看门狗；主机测试不证明硬件总线、ISR 执行时间和停机电气行为，后续须分项实测。
