## 参数与方向

2026-10-18用户现场确认：按小车前进方向看，最左探头对应OLED第1位。因此 `GROUND_IR_DIRECTION=1`，通道0为物理左；白1黑0，二值黑线质心索引0～7。P控制 `turn=-2*error`，限幅±4 RPM。正turn令左轮较慢、右轮较快，朝物理左纠偏。基速10 RPM，目标轮速范围6～14 RPM，PWM上限150/999，沿用正常RPM速度控制及编码器保护。这组转向参数是首次地面循迹起点，尚不代表稳定循迹已验证。

红外在前台每10ms扫描，保留PA2上拉和74HC4051选线、每路100us建立时间，完整帧在临界区一次发布。控制中断只使用缓存，不执行红外等待。没有黑线、滤波后黑色覆盖超过4路、数据超过40ms未更新、噪声标志有效或顺序未配置时拒绝起跑；倒计时末和运行期间不满足同样条件即以104号原因停车并锁定，不尝试盲走找线。原始全白/全黑立即停车，不等待去抖确认。前台心跳100ms、控制周期、堵转、反向、超速、按键与10秒时限保护保留。

## 现场步骤

1. 先在无岔路、无路口的白底直黑线上测试，前方至少1米空间。探头安装高度保持此前校准高度，黑线位于中间探头下方，屏幕IR中间出现0、两边为1；例如11100111。全白或全黑不能启动。
2. 确认屏幕LINE READY，松开两个按键，再拔掉串口和ST-Link，主控/电机维持电池供电。ST-Link电源输出不与电池并联。
3. 长按Start至少1秒再松开，倒计时3秒；期间不要移动小车。随后以10 RPM基速纠偏运行，10秒自动取消输出。
4. 有异常立即按ModeChange，必要时断电。丢线、过宽黑色和数据失效会显示FAULT STOP，F:104。路口/宽黑带也会触发这一保护，本轮不测试路口。
5. 停稳后保持供电，不复位，接回ST-Link信号线/GND（不接其电源输出）读回。每次上电只允许一轮，断电会丢失RAM记录。

观察是否朝黑线纠偏、是否振荡/越纠越偏、是否丢线停下。编码器速度记录不能单独证明循迹成功，需要现场轨迹观察。实板核对版本 `GROUND_IR_DIRECTION=0` 显示LINE MAP CHECK，任何按键都不能起跑；方向确认后才换为可运行版。
