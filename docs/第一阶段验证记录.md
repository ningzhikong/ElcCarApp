# 第一阶段验证记录

日期：2026-10-16。分支：`feat/usart1-autotune`。本次没有连接串口、烧录固件或驱动电机。

## 实现范围

固定 PCB 接线下复用 USART1，正常模式服务视觉，Start/PB14 启动选择的调参模式服务主机。已实现有符号编码器差分、浮点滤波、TIM1 定时速度控制、前台目标超时、异常关闭 PWM、非阻塞按键、OLED 分片刷新、固定阶跃实验与主机校验/双轮评分。

当前只提供固定参数实车实验入口。AI 自动候选搜索、物理速度换算、实车增益与限制标定、硬件看门狗、路线标记事件和外环改造仍是后续工作。

## 编译

命令：`python tools/build_firmware.py`。工具：本机 Keil ARM Compiler 5.06 update 5 build 528，MicroLIB，Cortex-M3。

- 编译、链接与 HEX 生成成功，0 错误、0 警告。
- ROM：31420 字节；RW+ZI：12440 字节，含 4KB 栈与采样缓冲。
- 静态前台调用栈估计峰值 984 字节；报告含间接调用/循环未知项，不能据此声称已测得实际最坏栈使用。
- 所有输出位于忽略目录 `.build/firmware/`，原提交的旧 HEX/AXF 不是本次构建结果。
- Keil IDE 工程已收录新增源文件；本次验证使用独立构建脚本，未执行 IDE 下载流程。

## 主机验证

命令：`python tests/run_host_tests.py`。本机 GCC 4.9.2 编译实际 C 源码，以模拟 HAL/寄存器代替硬件。

18 项 C 场景通过：

- 编码器有符号回绕、全部 16 位差分范围、正负低速滤波、PID 重置与输出限制。
- 未 ARM 启动拒绝、NaN/超范围/非整数 PWM 上限/异常请求编号拒绝。
- 待应用 RUN 的 STOP 取消，定时边界应用后才 ACK。
- 固定实验完成、111 条记录和导出边界。
- 心跳超时、方向错误、堵转、本地按键、UART 错误、非法帧、接收队列溢出停机。
- 实际控制引擎的周期配置、采样方向、目标过期、周期异常、立即取消输出、零目标制动、DWT 回绕、非有限目标拒绝。

9 项 Python 测试通过：读取 C 状态机在模拟 HAL 下生成的真实协议格式，验证主机适配、双轮评分、完整记录、错误目标、非法输出、错误周期、非有限遥测、停止段输出与实际参数确认。

以上测试没有使用主机模拟结果冒充实车数据。主机脚本仅在实际打开串口完成试验且通过校验后标记 `source=real_motor`。

## 首次上板仍需验证

1. PCB 的视觉插座针序、3.3V TTL 电平与 Start/PB14、PB15 按键对应。
2. HELLO 握手和 VIEW 只查询不驱动；人工转轮确认左右编码器符号。
3. 实际 10ms 周期、ISR 执行时间与栈余量；OLED/通信对控制的影响。
4. 取消驱动、PB15、断开通信、堵转/方向/超速保护的实物行为。
5. 电机启动死区、合理输出上限、速度阶跃与重复性；确认后才运行参数比较。

这些项目属于后续硬件验证，本记录不将其标记为已完成。
